Please note that `language` data element is disallowed in the [data minimization](profiles.html#data-minimization-and-privacy) profiles of this IG. Inclusion of this data element in examples is an artifact of the [IG Publisher](https://confluence.hl7.org/spaces/FHIR/pages/35718627/IG+Publisher+Documentation) generating examples without a mechanism for suppressing this element. Implementers should omit `language` when conforming to data minimization profiles.
